# 星露谷 AI 伙伴

伙伴可用自然语言保存、修订和召回游戏经历与可参考的方法，按当前话题和场景取用；方法由模型结合现场自由组合已有工具，不运行固定业务流程。记忆更正在原会话继续生效；玩家也会改变世界，历史经验不能替代当前观察。

聊天与主动问候共用实时工具；补充要求在工具边界接入，当前动作正常完成。工作进度显示在左上角，与玩家的对话进入聊天栏。

伙伴按游戏现状逐步执行并复查，优先完成当天照料；中断后核对剩余工作再继续。回复直接进入游戏聊天栏，整段自动换行，F8 保留记录。
给《星露谷物语》添一个能聊天、记住约定、在游戏里实际干活的 AI 伙伴。

你可以和她商量今天做什么，再交代浇水、收获、播种或整理物品；干活时也能聊天、改变后续安排。伙伴使用自己的背包、工具和体力，进度可以在游戏里查看。

伙伴按实际碰撞选择可走路线，遇到障碍会先判断是否适合清理，再决定继续或改道；采木优先成熟树，保留幼树。砍倒数量确认后接着拾取、入箱，不因树已消失而重复找树。靠近普通掉落物会自动拾取，背包满时留在地上；清理杂物按玩家要求或通行需要安排。

**[下载 Windows 完整包](https://github.com/CSXizhang/star/releases/latest) · [详细安装指南](docs/release-guide.md) · [玩家指南](docs/companion-guide.md) · [反馈问题](https://github.com/CSXizhang/star/issues)**

F8 设置可选择伙伴或 AI 自己玩，重启生效；自玩仅限单人，聊天栏随时指导，F9 托管或接管。Windows 下载版启动时提示更新，确认后下载、校验、退出安装并重启；退出前请睡觉保存。连续对话仅发送变化的游戏状态。

## 开始使用

伙伴自然交流保留在聊天栏，工作进度显示在左上角。动作返回最终结果，收获与清障附带掉落物和背包观察；AI 可指定休息恢复目标。选项收到后立即保存，退出游戏先取消本轮模型执行，再清理所属进程。

伙伴的普通消息直接显示在游戏聊天栏，按 T 或点击左侧状态栏输入，回车或点击“发送”提交指导与回复。需要选择时使用 NPC 选项，也可在聊天栏作答；F8 保留任务、记录和设置。

当前源码新增两条接入路径：在游戏内启动伙伴，或由已有 MiniMax Code 会话主动连接；原会话失联时不会自动换一个 AI，聊天显示名随所选来源切换。读档保留伙伴会话并重新核对世界，两条路径已通过各三个游戏日的[隔离实机验证](docs/dual-connection-validation.md)，连接与首版限制见[已有伙伴接入](docs/mcp.md#已有-minimax-code-伙伴主动连接)。这些改动尚未发布。当前源码也已接通记忆与自然语言方法召回，以及原生能力的接口发现、C# 构建、当前游戏热加载试用和版本保存回退；玩家商量好范围后可在当前存档试用，成功后留待下次使用，详见[成长与延续](docs/companion-efficiency-and-play-design.md)。新增能力的实机验收与上述双路径验证分别记录。

### 1. 准备游戏和一个模型客户端

你需要：

- **Windows 64 位**，已安装《星露谷物语》和 [SMAPI](https://smapi.io/)。本轮验证环境是 **Stardew Valley 1.6.15 / SMAPI 4.2.1**，主要面向单人存档。
- **任选一个模型客户端，安装并登录**，目前已测试：MiniMax Code（`mcode`）、Codex CLI、Kimi CLI、agy 或 dsh。

完整发行包已经包含 Mod 和独立 Python 环境。已有模型客户端就沿用它，后端选择说明见[模型登录与工具信任](docs/release-guide.md#模型登录与工具信任)。

### 2. 下载并安装

1. 打开 [Releases](https://github.com/CSXizhang/star/releases/latest)，在 **Assets** 下载 `StardewAI.Companion.Mod-0.3.21-windows-x64.zip`。
2. 完整解压，进入 `StardewAI.Companion.Mod` 文件夹。关闭游戏，双击 **设置星露谷伙伴.cmd**。
3. 选择游戏目录，也就是能看到 `StardewModdingAPI.exe` 的文件夹；左侧选模型客户端，右侧填模型，然后点 **安装并应用设置**。
4. **Codex 和 MiniMax Code 的模型可以留空**，沿用客户端当前配置。其他后端按账号实际可用模型填写。

安装后的目录应类似：

```text
Stardew Valley/
├─ StardewModdingAPI.exe
└─ Mods/
   ├─ 你原来的其他 Mod/
   └─ StardewAI.Companion.Mod/
      ├─ manifest.json
      ├─ StardewAI.Companion.Mod.dll
      ├─ runtime/
      └─ 设置星露谷伙伴.cmd
```

**可以和原有 Mod 放在同一个 `Mods` 目录使用。** 已有伙伴请升级原文件夹，避免同时加载两份；使用自定义 `--mods-path` 启动器时，要安装到它实际读取的目录。其他 Mod 的兼容性取决于具体组合。

Kimi 用户首次使用还需在**安装后的伙伴文件夹**运行 `kimi`，确认项目与工具信任。其他后端的首次连接步骤见[安装指南](docs/release-guide.md)。

### 3. 进入游戏，和伙伴说第一句话

通过 **SMAPI** 启动游戏并进入存档，伙伴服务会自动启动，通常无需另开“启动伙伴服务”。按 T 或点击左侧状态牌打开聊天；走近伙伴按交互键可以面对面交谈，F8 查看工作与设置。

初次见面可以给伙伴起名字、选择相处方式。选择 **直接回复**，输入文字，按回车或点 **说出** 发送。先从一件小事开始：

| 你可以这样说 | 用来做什么 |
| --- | --- |
| 今天我们做点什么？ | 结合当前农场商量安排，先听建议。 |
| 先把农舍前这片作物浇完，现在开始。做完告诉我。 | 确认一项具体任务，让伙伴实际行动。 |
| 这片做完后先停下，别继续别的地。 | 干活中修改后续安排，已开始的动作可能先收尾。 |
| 实际做了多少？还有什么没完成？ | 核对执行结果和遇到的阻碍。 |
| 以后晚上十一点回家休息。 | 保存日常作息约定。 |

伙伴找不到“这片”时，可以补充附近地标或位置。需要工具、种子、食物等材料时，可告诉她去哪个箱子取；她使用的是自己的背包。

## 看进度、暂停和继续

按 **F8**，选择 **当前工作 · 暂停 / 取消**，可以查看安排、实际完成数量、等待原因和最近结果。**历史记录**用于回看聊天，**设置和用量**用于调整伙伴设置和查看模型用量。

- **暂停**：先停下，保留安排和进度；点继续或说“继续工作”恢复。
- **取消当前安排**：撤回这项工作及其后续接续，已经完成的成果保留。
- **主动帮忙**：决定空闲时是否自行找事做。关闭后，仍会执行你明确交代的任务。

模型回复有时需要几十秒，复杂回合可能超过一分钟。状态牌会显示正在回复、排队或连接异常；伙伴聊天窗口打开时，游戏时间与动作仍会推进。

## 还能一起做什么

除了日常聊天、浇水和收获，还提供翻地播种、补水进食、清理杂物、箱子存取、出货采购，以及动物照料、机器加工和农场布局相关工具。可以从一个小目标开始，再逐步安排更长的项目，详见[玩家指南](docs/companion-guide.md)和[农场项目](docs/farm-projects.md)。

当前重点是单人农场合作。完整跟随、矿洞战斗、钓鱼和语音仍待扩展；社区中心献祭的实际提交需要玩家自行完成。

## 升级和常见问题

**从旧版升级：** 关闭游戏和伙伴服务，备份存档以及旧伙伴目录里的 `data`、`config`，再运行新包的设置向导，安装到同一目录。向导保留已有设置和伙伴数据；不要只替换 DLL。

| 遇到什么 | 先检查什么 |
| --- | --- |
| 进游戏看不到伙伴入口 | 确认通过 SMAPI 启动；查看 SMAPI 窗口是否加载了伙伴、是否有红字。 |
| 提示客户端缺失或连接异常 | 确认所选客户端已安装登录、能独立对话，再运行安装目录里的设置入口核对后端与模型。 |
| 能回复但没干活 | 查看“当前工作”的等待原因，检查是否暂停、材料或工具不足、目标无法到达；商量建议本身不等于开始工作。 |
| F8 与其他 Mod 冲突 | 用鼠标点击左侧伙伴状态牌，或走近伙伴交谈。 |
| 提示文件不完整或版本不匹配 | 重新下载完整包，关闭游戏后用向导升级，保留 `data` 和 `config`。 |

仍有问题可在 [Issues](https://github.com/CSXizhang/star/issues) 留下 Mod / SMAPI 版本、模型后端、你说的原话、伙伴回复与实际动作，并附相关报错或截图；不要上传账号密钥。更多排查见[安装指南](docs/release-guide.md#升级与排查)。

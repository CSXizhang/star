# 星露谷伙伴

延续当前 Codex 对话里的玩家目标，用已接入的 stardew-companion 工具和游戏中的伙伴合作。游戏状态以工具返回为准；不要假定外部 Codex 对话与游戏内聊天共享会话。

- 首先用 `get_status` 和 `get_work_overview` 确认当前存档、已有工作及结果。只观察时不提交任务。缺少工具时提示玩家在目标 Codex 项目运行发行包中的注册脚本，并重新打开会话；不要改写全局配置。
- 按任务需要使用观察工具；其他能力用 `discover_capabilities` 查参数，再用 `call_capability` 调用。不要猜物品、位置或能力是否存在。
- 玩家要求执行时，先用 `begin_game_turn` 开启本次决策，再使用 `submit_plan` 选择一个语义短作业，同一业务可含导航和连续原生操作；下一种业务在上一步终态后重新决定并开启新轮次。忙碌或暂停时先向玩家说明现状，不自动取消已有工作。`remember_intent` 记录目标，不代表执行授权。以工具当前 schema 为准。
- `job-selected` / `not_executed_yet` 只说明已选中；提交后用 `work_plan_overview` 查看持久化任务终态，避免 `get_status` 或 `get_work_overview` 再占用游戏唯一命令连接。避免密集轮询或重复提交。任务失败时根据错误调整；连接或权限缺失时停止重复尝试，说明阻塞原因。
- 外部 Codex 操作期间不要同时从 F8、NPC 聊天或自由模式派工。沿用已经运行的伙伴服务执行任务，不另起聊天桥接服务。游戏需已通过 SMAPI 载入存档，菜单关闭后农活动作才能继续。
- 用玩家的语言简短说明结果和未完成事项。保留玩家选择的称呼和相处方式，不把开发助手的身份或编码流程带入伙伴对话。

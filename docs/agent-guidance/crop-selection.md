# 种植选择

## 按目标和瓶颈选择指标

| 玩家目标或当前瓶颈 | 主要比较指标 | 会改变选择的因素 |
| --- | --- | --- |
| 赚钱、提高收益 | 到计划截止日的总净收益与每格收益 | 剩余生长时间、复种成本、产量、加工容量 |
| 优先高售价 | 单份售价；同时列出净收益 | 单份售价高但产量低、回本慢 |
| 土地不足 | 同一时间范围内每格净收益 | 多次收获、复种、格架通道占地 |
| 资金不足 | 可负担规模与回本时间 | 贵种子减少可种数量，首收影响下一次采购 |
| 体力或工作时间不足 | 每天照料量与总操作量 | 种植规模、重复播种、补水距离、收获频率 |
| 指定数量或指定作物 | 完成条件与完成速度 | 种子来源、可执行田区、播种后浇水进度 |

普通赚钱目标先比较土地收益，再用当前瓶颈调整规模。指定作物、用途和数量进入方案约束。现有种子减少现金投入，同时占用土地与照料时间，和采购方案一起比较。

## 按当前日期计算收获与净收益

选出两三个有竞争力的候选，取得季节、首收天数、再生间隔、每次产量、种子采购价与普通售价。先写出当前日期下的收获日历，再按同一截止日比较净收益。

设播种日为 `d`，最后可收获日为 `L`，可生长天数 `H = L - d`，首收需 `g` 天：

- 单次收获且立即复种：`收获轮数 = floor(H / g)`，每轮都计种子成本。
- 再生作物：`H < g` 时无收获；否则 `收获轮数 = 1 + floor((H - g) / 再生间隔)`，种子通常只买一轮。
- `净收益 = 各轮产出价值之和 - 种子及其他新增投入`。比较同一截止日的方案时，使用相同时间范围。

播种当天浇水、成熟当天收获并及时复种是这些公式的前提；超过截止日才会成熟的最后一轮不再复种。施肥、职业、生长中断和跨季作物会改变日期，遇到相关条件时重新排收获日历。截止日变化会翻转结论，按当前日期重算。

## 确定采购量与照料规模

采购决定记录作物、数量和决定性理由。数量取决于目标缺口、主田区容量、可用资金与每天照料能力；资金不足时，把首次回款和后续扩种纳入安排。

保留已经安排的建造、购鸡和必要饲料费用，依据具体项目计算预留金额。水量与体力影响当前批次大小，可以补水、进食后继续原田区。

有加工目标时，按现有机器与可用时段估算容量。能进入实际加工排期的产量采用加工价值，其余按计划中的出售或留存用途处理。

有累计数量目标时，根据完成记录补齐剩余成果，达标后转入其他目标。日常浇水与天气安排见[日内节奏](daily-rhythm.md)。

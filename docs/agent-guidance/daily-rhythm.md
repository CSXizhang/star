# 日内节奏

## 晨起确定当天的机会与缺口

读日期、天气、节日与项目接续记录，更新当天照料、成熟产物、营业窗口和可采购事项。用这些变化安排今天的工作重点，已有田区与生产布局继续沿用。

雨天按实际湿润状态减少室外作物的日常浇水，把腾出的时间用于采购、养殖、加工或其他目标。玩家要求累计实际播种后浇水时，成果仍按执行记录统计，并补齐该项要求。室内种植等未受雨水覆盖的区域按自己的照料需求处理。

节日分别判断常规服务是否可用、店主日程是否改变，以及特殊采购是否有助于当前目标。值得利用的短窗口进入当天行程。

## 白天围绕窗口安排工作

营业与限时机会需要路程和办事时间；施工、成长与加工的等待适合穿插其他分支。当前作业做到合适边界再切换，给下一窗口留足准备与行程时间。

根据下一批工作需求安排补水、进食与背包整理。可无损留存的机器成品顺路集中收取，有限窗口优先安排。

## 晚间收尾与过夜

按玩家作息倒推收尾与返程，默认游戏内午夜0:00前上床（bedtime=2400），自定义时间以profile与快照为准。提前至少一小时停止新增长任务，并考虑真实路线需要；当前动作在安全边界核实结果后收尾，剩余目标与材料留给明天。

伙伴的原生作息控制器负责真实导航回家、走到床边、确认床位后入床；只在sleeping及sleepStartedAt实际出现时称已睡下。缺床或通路受阻说明具体原因，不冒充已上床。伙伴休息不强制玩家结束当天；次日根据伙伴自己的真实入床时间恢复体力。工作暂停与就寝分开记录，不为睡觉解除玩家暂停。

跨日后读取新日期与保存结果，更新照料和生产接续。数量达标的目标保持完成，持续经营进入下一天的必要工作。

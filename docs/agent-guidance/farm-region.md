# 田区规划

## 先选主田区，再安排格子

首次种植取得成片区域候选。每个候选提供区域边界、连续可用面积、障碍类型与数量、入口、到水源和主要工作地点的路线，以及相邻扩张空间。

比较以下条件：

1. 能否进入区域，并完成浇水与收获；格架作物保留可操作通道。
2. 当前区域加相邻扩张，能否容纳计划规模。
3. 清障与开垦投入是多少，已有耕地能否复用。
4. 每天补水、照料和收获要走多远，能否与鸡舍、机器和箱子的动线衔接。

工具提供候选事实，模型选择田区。一次清理几件杂物能换来近水源的连续田区时，将清理后的区域纳入比较。

选定后保存主田区边界、入口与通道、优先扩张方向。后续先填区内空格，再沿边界连片扩张；补水、采购和跨日后返回原田区。

## 比较准备成本与后续维护

比较当前连续可用面积、相邻扩张容量、清障工具与体力投入、补水往返距离和预计照料天数。`预计总投入 = 一次准备成本 + 单次维护成本 × 预计维护次数`；不同成本无法可靠换算时，分别列出时间、体力和材料作取舍。

## 扩张、换址与清障

批量作业选相邻格子，按行或可达顺序推进。`区内补种量 = min(目标剩余量, 区内可用容量)`；剩余缺口沿边界扩张。分批上限只影响每批大小。

主田区容量不足、长期维护成本明显更高，或玩家改变土地用途时，重新比较候选。已有作物继续照料，新增种植转到选定区域，记录换区理由与新布局。未锁定位置自主调整。

道路被杂物堵住时，比较一次清障成本与预计绕路总成本。`预计绕路总成本 = 每趟额外时间 × 预计经过次数`，与清障时间、体力和工具要求比较。工具与体力允许时清通必要通道，再继续原工作。

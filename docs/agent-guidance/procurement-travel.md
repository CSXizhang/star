# 采购与行程

## 用到达时刻判断是否出发

采购或拜访前查看当天营业、天气、节日、店主能否提供服务与路线。计算 `预计办完时刻 = 当前时刻 + 准备时间 + 行程时间 + 办事时间`，与可用窗口比较。店主在房间内、正在施工或参加活动时，确定目标服务是否可用。

预计办完时刻晚于窗口结束时改做其他工作。窗口不可用时，按核心接续规则记录下一次机会；商量耗时已使原窗口紧张时，复核出发条件。

雨天释放的日常浇水时间可用于采购与其他分支。节日可能改变营业和店主日程，也可能提供特殊种子或商品；按目标判断当天值得利用的机会。

## 一次出门准备完整

目标差额扣除现有库存，得到采购与办理事项。带齐建造材料、工具、食物和背包空间；资金覆盖本趟采购及已安排的近期必要支出。

顺路合并工作，以营业窗口和依赖先后为准。先完成即将关门的商店，再做无窗口的采集；建造需要材料时先取材料，再拜访木匠。关店后比较已知可用的其他来源、价差和额外行程。

体力低时，按下一批动作需求选择已有食物，进食后返回原工作。休息与跨日安排见[日内节奏](daily-rhythm.md)。

## 让行程适合剩余时间

出发时同时计算办事、返程与当天必要收尾的时间。闲时活动选择附近且能在空档内结束的内容；营业窗口接近时提前出发，深夜行程按[日内节奏](daily-rhythm.md)收尾。

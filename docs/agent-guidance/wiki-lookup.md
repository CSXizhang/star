# 知识查询

知道页面名称时用 `query_wiki(query=页面名, exact_page=True)`；结果会给出章节目录，需要具体表格时再传 `section=章节名`，复用同一正文缓存。名称不明确时先搜索确定页面。

## 确定需要补齐的字段

| 决策主题 | 查询字段 |
| --- | --- |
| 作物选择 | 季节、首收天数、再生间隔、每次产量、种子采购价与普通售价 |
| 加工选择 | 可用原料、品质影响、产物价值与加工周期 |
| NPC行程 | 相关营业、特殊日程与节日变化 |

按确切物品和问题定位页面。作物页取得生长与产量，种子页取得各来源的采购价格；已有数据足够后直接计算当前方案。候选明显落后、且没有会改变结果的特殊条件时，结束该候选研究。

## 返回决定所需的事实

查询结果包含：

- 主体：物品或主题名称，以及需要区分的身份。
- 事实字段：当前决策所需的机制、周期、产量或价格。
- 适用条件：季节、购买来源、品质、职业、肥料或加工条件。
- 来源：页面链接与对应表格或段落。
- 核对时间：查询日期；存在版本差异时记录适用版本。
- 待补信息：仍缺失且会影响选择的字段。

## 将资料转成当前方案

读取对应表格后，按当前日期、购买来源、职业与已有机器计算。先确定首收能否进入计划范围，再比较收益；跨季经营使用实际计划截止日。

缓存按物品与主题保存，后续复用字段。换季更新候选与收获日历；新增职业、肥料或加工方式时补查受影响字段。查询与观察矛盾时，查明影响差异的规则。

页面没有覆盖关键问题时，读取相关段落或关联页。暂时取不到资料，选择已有数据支持的方案，或推进不依赖该知识的其他工作。

# 和伙伴一起生活

本项目按单人体验设计。多人模式下，建造、购买动物、搬迁建筑和躺床恢复暂不支持。

安装与模型连接见[首页](../README.md#开始使用)和[接入指南](mcp.md)。进入存档后，走近伙伴按交互键开始交谈；F8 用来查看记录、管理工作和设置。

## 第一次见面

第一次走近伙伴交谈，她会先打招呼，再问你想怎么称呼她。输入一到十二个字的名字，然后简单选“多帮帮忙”“多聊聊天”或“先相处看看”。确认保存后，头像下和后续交谈就会使用你起的名字。

“多帮帮忙”会在保存约定后，尝试接手一件眼前的农活；忙碌和暂停中的工作照旧。“多聊聊天”增加伙伴消息，“先相处看看”不安排新工作。名字和相处偏好分别保存在当前存档的设置与约定中。

也可以稍后再说，之后从“说点别的……”里的“伙伴设置”调整。已有名字、性格和约定会保留；以前只保存过设置但还没完成初见的存档，只补问相处方式。

性格有温柔、活泼、沉稳、嘴硬心软四种。关怀频率可选安静、适中或健谈；安静档关闭主动消息，你仍可以随时找伙伴聊天。

你可以直接和伙伴选择一个方向，也可以随便聊聊、交代一件具体的事。方向随时能换，不需要重新起名或填写一套设置。

| 方向 | 可以一起做什么 |
| --- | --- |
| 赚钱 | 根据当前资源安排收获、出货、采购与补种 |
| 帮助干活 | 分担浇水、收获、动物照料、机器收取等日常杂务 |
| 装修农场 | 观察农场、安排布局、清理与分区施工 |

方向是长期偏好，切换后保留当前工作与暂停状态。社区中心物品仍可在直接对话里讨论和安排准备；献祭提交目前仍需玩家完成。项目进度见[自主生活与农场改造](farm-projects.md)。

## 直接对话与当前计划

走近伙伴按交互键，打开 NPC 对话框，保留头像、姓名和分段台词，下面直接输入、回车发送。闲聊、提问、派活和修改安排都在这里。按 **F8** 打开独立的记录窗口，滚轮、PageUp / PageDown 或拖动滚动条回看历史；查看旧记录时新消息不会强行滚到底部。

在 F8 的工作页选择待决定事项，会转到 NPC 对话框；输入选择并点“确认选择”才正式答复该事项。普通回车发送独立聊天，不关闭事项。决定成功确认后转为已答复，原问题和回答保留在历史中。事项也可直接删除、清除全部或在 8 秒内撤销；删除状态持久保存，删除不等于批准执行。

“把这片地浇完”会直接安排执行；“你觉得养鸡怎么样？”先讨论；“就按这个来”承接刚才的方案开始。明确交代“现在开始”或“继续工作”可以恢复暂停，普通聊天与改偏好不会解除暂停。

聊天面板和当前计划保持打开时，世界与伙伴动作继续推进；游戏本身的暂停、剧情以及其他普通菜单仍保留原有行为。回复显示在连续对话中，伙伴通常先简短回应，有需要可以追问细节。

F8 的工作页集中显示当前安排和待决定事项；设置页可以修改名字、方向、性格、交流频率、主动帮忙，查看偏好与约定及模型用量。作息可以直接告诉伙伴。查看记录不会额外调用模型。用量分别显示现实日期的今日全部存档、今日当前存档和当前存档累计；输入包含缓存，未记录部分明确标出，费用只在有可靠记录或配置价格时显示。

Codex、dsh 与 mcode（MiniMax Code）伙伴默认使用 low 推理，明确选择其他档位时使用所选值。dsh 可以选择 `deepseek-flash`；mcode 留空模型时沿用本机默认模型，连接方式见[发行包指南](release-guide.md)。

## 工作控制

从对话的“更多 → 查看当前计划”打开计划面板，可以查看当前方向、安排、正在做的动作、实际完成数量、等待原因、最近结果和下一步，并回看最近八条执行记录。通过对话接受的安排也显示在这里；做完后会保留结果，方便回看。面板里的“对话”返回同一个输入窗口。

“安排”显示你交代的目的，不需要填写坐标、工具名或执行约束。“当前”和“最近结果”使用具体任务名，例如“鸡舍扩建已下单，等待施工”；下一步显示已保存的后续安排。详细执行与失败原因保留在工作记录中。主动汇报通常不超过三句；想了解为什么这样安排，可在聊天中说“展开讲讲”，查看取舍理由、相关数据和未核实之处。主动帮忙的设置里可选空闲时自主安排、清理农场、采集、砍树取木或安静待命；这是偏好，已有项目与紧急农活优先，并需有相应工具。暂停后空闲活动也会停止。

从伙伴对话选择“看看任务进度”也会打开这个面板。完成的工作会显示“已完成”以及具体任务结果；例如浇水任务完成后，可以在“当前”和“最近结果”看到已完成的浇水安排。

也可以在面板里直接交代具体工作，或返回伙伴对话商量。伙伴聊天与计划面板打开时，农活动作也能继续。

- **暂停 / 继续**：保留当前指令、进度和待办。普通聊天、闲时机会和机器成熟都不会解除暂停；点击继续，或明确说“继续工作”才恢复。
- **空闲时主动帮忙**：开启后，伙伴在没有明确任务时按偏好安排工作；关闭后仍完成已接受的任务，做完再待命。这个开关不改变暂停状态。
- **取消当前安排**：结束当前安排及其后续接续，保留已经完成的成果。空闲时是否再主动工作由主动帮忙开关决定。
- **暂缓计划**：停止这项计划的后续准备安排；已经开始的当前动作，用暂停或取消控制。

按钮显示“请求中”时，等待服务确认。较长的任务内容可以滚动查看，未发送的草稿会保留。

面板的“今日用量”按电脑的现实日期累计本安装记录的工作与生活对话，跨游戏日期、跨存档累计；输入数已包含缓存，输出包含思考，不再重复相加。缺失的记录显示未记录。玩家自行管理用量，没有每日 token 上限或费用上限。

后端提供费用时显示已提供金额；未提供时显示费用暂不可用。可在 `config/usage-prices.json` 按后端和模型填写每百万 token 的 `uncachedInput`、`cachedInput`、`output` 和需要时的 `cacheWrite` 单价，面板据此显示“API 等价估算”，不代表订阅账单。格式见 `config/usage-prices.example.json`，该配置只影响展示。

## 作息与上床

伙伴默认争取在游戏内午夜 **0:00** 前上床。可在“说点别的……”→“作息”选择晚上十点、十一点、午夜或凌晨一点，也能直接说“以后十一点睡”。自定义时间范围为晚上 18:00 至凌晨 1:00。

伙伴根据返程距离提前收尾，保留未完成工作，真实走回家并上床；计划面板显示收尾、回家、已就寝。没有床或床被占用时会提示；中途路径受阻会稍后重试，可能晚于设定时间入床，部分提示会随重试更新。明确暂停时不会自行返程，继续后再执行作息。

伙伴先休息不会替玩家结束当天。入床时间独立记录，次日恢复体力并按新状态接续任务。你仍掌握自己何时睡觉与推进游戏日期。

## 记忆与伙伴消息

在“查看记忆”里可以新增约定、纠正记错的内容或删除旧约定。偏好帮助伙伴了解你的习惯；当轮明确说出的要求优先。共同经历根据真实工作结果记录。

适中或健谈档会偶尔收到与当天日期、天气或工作有关的消息。“伙伴消息”里可阅读正文和最近消息，安静档不主动提醒。

## 节点与准备

节点规划目前围绕近期准备，例如春季蛋蛋节的草莓种子、社区中心所需的春季作物。节点按存档保存，并展示日期与准备缺口；临近时按关怀设置提醒。

采购、建造和买动物按玩家目标与实际资金安排，无需设置每日购买额度。计划中的保留金额是规划提醒，不冻结资金。玩家金币与伙伴可花的钱分别读取。节日摊位购物与献祭提交由玩家亲自完成。

草莓节点核实的是可见种子数量，种植与浇水另看工作结果；收集物品齐备也不等于已经提交献祭。背包证据不足时保持待核对，因为物品可能放在箱子里或已经种下。

商量时可查官方英文 Wiki，结果附来源与查询信息。正文读取失败会退回搜索摘要，并说明哪些细节尚未核实；英文资料与游戏版本可能存在差异。

## 当前范围

伙伴使用自己的背包、工具和体力，工作会受材料、距离、障碍、背包空间与营业时间影响。睡觉和推进游戏日期仍由玩家掌握。批量农活与养殖加工的持续安排见[持续经营](farm-projects.md#持续经营)。装修的放置、回收、制作、建筑服务与移动范围见[施工说明](farm-projects.md#施工范围)。献祭实际提交进度、完整跟随，以及矿洞、战斗、钓鱼和语音等能力仍待扩展。

连接或模型报错时，请查看[故障排查](mcp.md#常见问题)。

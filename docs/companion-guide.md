# 和伙伴一起生活

安装与模型连接见[首页](../README.md#开始使用)和[接入指南](mcp.md)。进入存档后，按 F8 交代工作，或走近伙伴按交互键，像和镇上NPC说话一样开始交谈。

## 第一次见面

第一次走近伙伴交谈，她会先打招呼，再问你想怎么称呼她。输入一到十二个字的名字，然后简单选“多帮帮忙”“多聊聊天”或“先相处看看”。确认保存后，头像下和后续交谈就会使用你起的名字。

“多帮帮忙”会在保存约定后，尝试用现有资源做一件眼前的农活，不开启自由模式或采购；忙碌和暂停中的工作照旧。“多聊聊天”增加伙伴消息，“先相处看看”不安排新工作。名字和相处偏好分别保存在当前存档的设置与约定中。

也可以稍后再说，之后从“说点别的……”里的“伙伴设置”调整。已有名字、性格和约定会保留；以前只保存过设置但还没完成初见的存档，只补问相处方式。

性格有温柔、活泼、沉稳、嘴硬心软四种。关怀频率可选安静、适中或健谈；安静档关闭主动消息，你仍可以随时找伙伴聊天。

你可以直接和伙伴选择一个方向，也可以随便聊聊、交代一件具体的事。方向随时能换，不需要重新起名或填写一套设置。

| 方向 | 可以一起做什么 |
| --- | --- |
| 装修 | 商量农场布局，按选定区域安排清理与材料准备 |
| 献祭 | 商量所需物品，安排收集、保留和种植准备 |
| 赚钱 | 根据当前资源商量收获、出货、采购与补种 |
| 干活 | 分担浇水、收获、动物照料、机器收取等日常杂务 |

选方向后，伙伴会结合当前农场提出安排。方向只是偏好，不会替你强制开启自由模式；先商量具体方案，再决定是否开始。家具摆放和献祭提交目前仍需玩家完成。

## 聊天、商量和交代工作

近身交互打开游戏原生人物对话窗口，显示伙伴名字和头像；正文自动换行，长回复会分页。可以随便聊聊、选择方向，或输入自己想说的话。聊到想做的事情时，选择“就这件事商量安排”，会接着你刚才的话讨论，不用重新输入。

有具体方案后，可以选“按这个安排”，也可以调整、换方向或看看任务进度。没有形成方案时不会出现开工确认按钮。聊天与商量都在同一段交谈中继续。

伙伴思考或执行时会先让你继续活动，不用守着暂停中的对话框。回复到达后会有一次提示，走近伙伴就能接着读；它不会抢占正在看的其他菜单或剧情。再次交谈也可以选择“接着刚才聊”回看最近答复。

“说点别的……”里可以查看约定、伙伴消息和设置。对话中的“看看任务进度”和 F8 打开同一个伙伴任务面板。


- **随便聊聊**：聊农场生活、心情和近况。这个入口只读，不改变工作或计划。
- **帮我做件事 / F8**：交代具体工作，例如“把成熟的菜收起来”。可以查看过程和结果，也可以暂停或取消。
- **商量计划**：讨论接下来做什么，查看近期节点与准备安排。伙伴结合游戏日期、资源、性格和偏好提出方案；认可后保存，之后也可修改或暂缓。

伙伴先看实际资源提出方案，点击“按这个安排”后保存并接手当前可做的准备。当前工作忙、暂停或尚未到时间时，任务面板会说明等待原因。实际进度与完成结果来自工作反馈。

## 工作控制

按 F8 打开伙伴任务面板，可以查看当前方向、安排、正在做的动作、实际完成数量、等待原因、最近结果和下一步。通过 NPC 对话确认的安排也显示在这里；做完后会保留结果，方便回看。

也可以在面板里直接交代具体工作，或返回伙伴对话商量。发送工作后窗口会关闭，让游戏继续推进；菜单打开时农活动作会暂停推进，关闭后继续。

- **暂停 / 继续**：保留当前指令和进度，之后接着做。
- **取消**：结束当前指令，等取消确认后再安排新工作。
- **暂缓计划**：停止这项计划的后续准备安排；已经开始的当前动作，用暂停或取消控制。

按钮显示“请求中”时，等待服务确认。较长的任务内容可以滚动查看，未发送的草稿会保留。

## 记忆与伙伴消息

在“查看记忆”里可以新增约定、纠正记错的内容或删除旧约定。偏好帮助伙伴了解你的习惯；当轮明确说出的要求优先。共同经历根据真实工作结果记录。

适中或健谈档会偶尔收到与当天日期、天气或工作有关的消息。“伙伴消息”里可阅读正文和最近消息，安静档不主动提醒。

## 节点与准备

节点规划目前围绕近期准备，例如春季蛋蛋节的草莓种子、社区中心所需的春季作物。节点按存档保存，并展示日期与准备缺口；临近时按关怀设置提醒。

计划中的保留金额是规划提醒，不冻结资金，也不替代每日购买上限。玩家金币与伙伴可花的钱分别读取。节日摊位购物与献祭提交由玩家亲自完成。

草莓节点核实的是可见种子数量，种植与浇水另看工作结果；收集物品齐备也不等于已经提交献祭。背包证据不足时保持待核对，因为物品可能放在箱子里或已经种下。

商量时可查官方英文 Wiki，结果附来源与查询信息。正文读取失败会退回搜索摘要，并说明哪些细节尚未核实；英文资料与游戏版本可能存在差异。

## 当前范围

伙伴使用自己的背包、工具和体力，工作会受材料、距离、障碍、背包空间与营业时间影响。睡觉和推进游戏日期仍由玩家掌握。献祭实际提交进度、装修施工、完整跟随，以及矿洞、战斗、钓鱼和语音等能力仍待扩展。

连接或模型报错时，请查看[故障排查](mcp.md#常见问题)。

请结合提供的玩家农场参考，在这座原始农场上建设一处以农舍周边为核心、中等规模、内容丰富的田园生活空间。

我们希望成品包含日常生活的庭院、实际可用的耕作空间和养殖空间。这些内容应当自然联系起来，让人能想象在这里居住、劳动和散步。建设范围无需覆盖整张地图，但希望从全景中能看出一片完整经营起来的农庄，局部也有值得欣赏的生活细节。

请借鉴参考作品的空间组织、材料搭配、植物层次和完成感，根据当前地形与实际能力发展自己的方案。各部分的位置、形状、大小、数量和施工顺序由你决定；原有树草可以成为背景、边界或小景。

请关注建成空间之间的衔接，以及它们与周边自然环境的过渡。道路、植物和装饰应当共同服务于整体设计，让设施放在一起显得协调、舒适、方便使用。

材料和采购资金充足，可以跨日持续工作，没有累计工作预算限制。由你自主清理、制作、建设、采购、种植和照料，并根据真实全景与局部画面调整设计。

完成时保存作品，介绍实际建成的生活场景、设计亮点与仍有的不足。尚未成熟的植物、未完成的建筑和暂未投入使用的设施，请准确说明状态。

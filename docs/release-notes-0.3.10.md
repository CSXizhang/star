# 0.3.10 — 退出后释放后台与安装文件

- 返回标题或正常退出游戏时，停止本 Mod 自动启动的后台服务及其子进程。
- 自动后台服务持有游戏进程身份；游戏被强制结束时，后台也会结束。若模型或线程阻塞退出，约 5 秒后强制结束这条后台进程树，释放随包 Python 文件。
- 启动与关闭同步处理，避免启动器检查环境期间退出后留下新进程。重新进入存档可以启动新的服务。
- 临时连接中断仍可重连；没有游戏 owner 参数的手动后台保留原有常驻行为，不按进程名清理其他 Python 或 AI 客户端。

沿用 0.3.9 的 Esc 关闭和此前动画、补水、恢复及自主行动修复。旧存档无需迁移。

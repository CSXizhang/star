# 0.3.11

伙伴可在一项可中断作业中组合导航、取料、开垦、播种和浇水，不再受整个作业 64 格、单一业务类别或同地图组合的限制。真实体力、水量、道路、暂停及原生命令终态仍决定实际进度。

已接下的安排可直接修改，保留同一目标。指定地点和候选格会完整保存；自动浇水、收获会按该范围选择当前真实目标。直接调用单步工具也继承当前目标，避免丢失约定。空范围、未知状态和截断观察分别处理。

执行回报保留各步骤的真实成功、跳过、失败、未处理数量和原因，供后续决策、工作记录与记忆使用。确定没有待处理工作时直接说明，不触发多余续轮。

agy 使用标准输入发送请求，提前保存会话标识；取消后清理本次进程树。用量按响应去重并支持迟到补计，最新输入上下文与累计使用量分别展示。

旧存档无需迁移。旧 `plant_crop_workflow` 名称保留，模型调用会在执行前提示拆为取种、开垦、播种和浇水，以便正确记录各步回执。

保留 0.3.10 的原生 F8 对话入口、Esc 关闭、床恢复、动作动画和退出释放后台进程。

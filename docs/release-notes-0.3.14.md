# 0.3.14 · 连续合作与日常农活

伙伴沿用已确认的安排，在聊天、农活执行、结果反馈和次日继续之间保留同一会话。玩家可以正常商量、派活或更改后续安排，执行结果按游戏实际回执报告。

- 去掉动作默认的游戏时间上限。正常走路、浇水、收获等工作可以持续推进，不会因为过去了 60 个游戏内分钟被强制截断；卡住检测改为观察是否持续没有进展。暂停、取消、真实体力和工具资源仍按实际情况处理。
- 修复玩家与伙伴身处不同地图时，浇水误用玩家地图判断水源的问题。浇水和补水都在伙伴所在地图调用原生工具，并恢复玩家地图上下文。
- 水壶已经装满时，补水作为已满足条件结束，继续后续工作，不再尝试其他水源后把整项作业判失败。浇水部分失败时保留具体格子和原因，供伙伴调整安排。
- 简化每轮提示，玩家原话直接进入对话；聊天和工作复用会话，移除 Mod 主动重开、强制整理上下文和重复完成播报。保留游戏用系统提示及 agent 框架原有能力，允许按需读取地图图像。
- 修复镰刀收获入口与作物保护的冲突，保留原生收获回执；改进伙伴对话的关闭与回复入口。已经完成的一批浇水不会因为整片田仍有缺水而阻止队列里的补水和下一批作业。

下载完整 `StardewAI.Companion.Mod-0.3.14-windows-x64.zip`，关闭游戏后运行包内“设置星露谷伙伴.cmd”。可与已有 Mod 安装在同一个 `Mods` 目录；升级保留伙伴配置和数据。需要 Windows x64、Stardew Valley、SMAPI 和已登录的模型客户端，详见[安装说明](release-guide.md)。

发布前真实游玩记录来自 0.3.14-repair.126：与本机原有 Mod 一起运行，原生记录确认收获 10 格、浇水 163 格，并进入下一天。上述时间限制与跨地图浇水修复在该轮之后完成；最终 0.3.14 的完整实机复测尚未完成，软件回归检查不代替实机验收。

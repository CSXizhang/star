# 0.3.15 · 按你的设定相处

人格、称呼、表达方式与作息以玩家的描述和已保存约定为准，预设性格只补充未指定的部分。

- 预设性格改为简短标签，不再附带工作数量、经营规模或固定交流方式。
- 主动交流沿用同一份人格和记忆，去掉 100 字上限及“让玩家感到温暖”的固定要求。
- DSH 使用统一的游戏系统提示，不再另加“只通过游戏工具”“一到两句”的限制。
- 日内指导根据剩余工作、返程路线与约定作息安排收尾，去掉固定提前一小时停止新任务的要求。
- 按需重新观察状态、查看地图；删除固定比较数量和每天必须完成某种选择的指导。

下载完整 Windows 包，关闭游戏和伙伴服务后，用“设置星露谷伙伴.cmd”升级原目录，保留已有配置和伙伴数据。使用说明见[安装指南](release-guide.md)。

本版只调整提示词与指导，不改变原生动作、资源消耗、暂停取消或任务完成判定。Wiki 直连在本机仍遇到 HTTP 403，本版尚未修复。提示词调整后的角色表现未做新一轮模型实机验收。

# 0.3.17

- **游戏内更新**：启动游戏后，有新版会弹出提示。点“下载更新”，下载完成后点“确认退出并更新”，安装好会自动重新打开游戏。设置和伙伴记忆都会保留。
- **让 AI 自己玩**：在 F8 → 设置 → 游戏模式与更新中切换，重启后按 F9 开始托管。随时按 F8 告诉 AI 接下来做什么，按 F9 拿回控制权。仅支持单人游戏，自玩功能的源码已公开。
- **减少重复内容**：连续对话不再每轮重复塞入整份游戏状态，只补充发生变化的部分；你输入的指令不会被删减。旧对话已经占用的上下文不会自动清空。
- **修好走路动画**：角色移动时正常迈步，不再像滑着走；停下或用完工具后恢复站姿。

旧版没有更新入口时，下载下方 Windows 安装包，解压后双击“设置星露谷伙伴.cmd”，安装到原游戏目录即可，无需重新设置模型。更新前请先睡觉保存。

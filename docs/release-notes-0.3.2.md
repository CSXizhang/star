# 0.3.2 更新说明

- 加入 MiniMax Code（mcode）后端：支持对话、工作规划、会话续接、游戏工具绑定和用量统计。
- 下载版设置向导可选择 mcode；模型留空沿用本机默认模型，新配置默认 low 推理，升级保留已有 mcode 模型和推理设置。
- 启动检查支持 Windows npm 安装及 Codex 应用缓存中的 mcode，并检查 Node.js 与 CLI 入口是否完整。
- 保留已有 F8 伙伴对话、待决定事项、用量显示和行动规划改进；本版本未修改已确认的伙伴提示词。

安装前退出游戏和伙伴服务，解压新包并运行“设置星露谷伙伴.cmd”。选择原游戏目录和 mcode；账号登录需先在本机 MiniMax Code 中完成。安装向导保留已有 data、config 和伙伴记忆，不复制账号凭据，不修改 MiniMax Code 的全局 MCP。

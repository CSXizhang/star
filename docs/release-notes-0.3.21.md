# 0.3.21 · 聊天更自然，干活有始有终

### 聊天与连续工作

- 伙伴的日常交流留在游戏聊天栏，工作进度显示在左上角，减少刷屏；F8 可查看完整记录。需要决定时仍使用 NPC 选项，也能直接聊天回答。
- 聊天与工作共用回合和八个游戏工具。干活中追加的要求会在工具边界送达，正常推进的长任务不会再被整轮时限强行打断。
- 连续回合只补充已送达状态的变化；动作失败也不会让下一轮重复发送整份上下文。重新启动游戏时，用短交接摘要开启新会话。

### 拾取、休息与移动

- 伙伴靠近地面掉落物会自动拾取；收获、采木后返回实际结果和剩余掉落物，便于继续收集、入箱。
- 拾取观察只列掉落物和可直接采集物，避免把捡材料误解成清理整片农场。采木优先成熟树，保留幼树。
- 可以指定休息恢复到多少体力；休息受阻后会结束旧行动，避免后台反复回床、抢占后续任务。
- 修正步行动画、前后遮挡和移动碰撞；寻路同时检查站立位置与途中碰撞。走不通时返回原因，让模型根据现场决定下一步。

### 已完成验证

固定的“伙伴实机回归”已在一次游戏启动、同一 mcode 会话中全部通过：

- 浇完 12 格作物、自动补水，并接收中途追加要求。
- 收获 5 个防风草、拾取 3 个木材并入箱；随后取出作物出货，木材保留，没有额外清理农场。
- 从 10 体力休息至 80，砍两棵成熟树，收集并存入 34 木材、12 树液，幼树保留。

上述场景同时核验了动作结束状态、步行动画变化和移动时的障碍碰撞。开发者可复用同名回归工具进行后续验收。

### 安装与更新

下载下方 `StardewAI.Companion.Mod-0.3.21-windows-x64.zip`，解压后双击“设置星露谷伙伴.cmd”，安装到原游戏目录。已有自动更新入口也可在游戏内检查更新；安装会保留配置、记忆与存档。GitHub 的 Source code 是源码，不是玩家安装包。

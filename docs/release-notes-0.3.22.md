# 0.3.22 · 原会话、持续记忆与能力学习

支持游戏内启动伙伴，或由 MiniMax Code 0.6.2 原会话主动接入；读档与重连恢复所选来源的同一会话。可保存、修订、召回经历和方法；缺少操作时可商量后查询原生接口、编译试用、保存并升级能力。

动作立即执行，普通回复进入聊天栏；新要求按确认送达状态接续，取消后在原会话继续。拾取、障碍观察及实际物品变化分别报告。

验证与限制见[双路径、记忆与能力验证](dual-connection-validation.md)；安装见[发行包指南](release-guide.md)，已有伙伴接入见[接入指南](agent-self-integration.md)。

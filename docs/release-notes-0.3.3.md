# 0.3.3 测试版更新说明

- 修复跨午夜用量归属：已留存的模型响应按各自的现实本地日期统计，终态到达和重启不会把整轮用量搬到同一天，也不会重复计数。缺少响应明细的终态差额仍作为带“未记录”标记的终态日期记录；跨日整轮费用不冒充某一天的费用，累计费用继续保留。
- 修复决定确认回包丢失后的恢复：已答复事项及其回答随存档持久保存，新增问题不再裁剪确认记录；重连可据此纠正客户端的“待决定”状态。旧版已经删除的记录无法凭空恢复。
- 包含 0.3.2 的 MiniMax Code（mcode）支持，以及本次检查发现的修复：Windows npm 安装直接通过 Node.js 启动，长提示词和中文从标准输入传递；已开始执行的请求不会因普通 session 错误自动重试；真正无法续接时，新会话重新载入核心规则。
- MiniMax Code 缺失的用量字段保持未知，明确的零保留为零，遵守服务端的用量不完整标记，超时或取消时保留本进程已收到的测量值。

## 安装与试玩

退出游戏和伙伴服务，解压 `StardewAI.Companion.Mod-0.3.3-windows-x64.zip`，进入包内文件夹运行“设置星露谷伙伴.cmd”，选择原游戏目录。要测试 MiniMax Code，请先完成本机 mcode 登录，再在向导中选择 mcode。模型可留空使用本机默认值。

安装使用现有正式安装器，保留玩家 data、config 和存档。本次只提供测试包，不自动安装到日常游戏目录，不修改全局模型账号设置。

建议测试 F8 中文长对话、待决定事项的“继续聊／确定决定”、关闭游戏后的历史恢复，以及 MiniMax Code 工作规划和暂停／继续。离线回归不能代替游戏内界面和真实模型执行验收。

# 0.3.4 测试版更新说明

- 恢复原生 NPC 头像对话、逐字显示和长文翻页。下方只保留输入与“更多”；历史、计划、用量和设置收进菜单，待决定事项才显示“确定”。
- 读档保留玩家目标、偏好、约定、预算规则与决定答案；中止旧工作，撤销旧执行凭据，并按游戏存档恢复已完成的事实。模型会话继续使用，附上读档说明与实时结构化意图摘要，后续工作重新观察世界再规划。
- 完整对话另行留存，界面保留最近记录；模型可以分页回读读档前原文，包含讨论过程、选择及理由。旧版已经丢失的原文无法恢复。已有存档首次使用此版尚无游戏内检查点时，旧执行事实按未核实处理；正常保存后才有完整回滚基准。
- 读档恢复必须在连接认证成功后、工作线程启动前完成。断线重连不重复恢复，旧连接回调不能污染新存档会话。模型消费记录不随游戏读档回滚。
- 重复确认已答复事项只返回原答案，不重新调用模型或执行控制；不存在或跨存档的决定编号仍被拒绝。
- 用量明细按模型响应的现实日期计入；终态与明细的差额显示为“日期无法确定，已计入累计”，不再归入终态当天。
- 包含 MiniMax Code（mcode）支持及 0.3.3 的 Windows 启动、长中文输入、恢复重试与缺失用量处理修复。

## 测试方法

退出游戏和伙伴服务，解压新包，运行包内“设置星露谷伙伴.cmd”更新游戏目录。原有玩家数据与设置由安装器保留。MiniMax Code 请先在本机登录，设置中选择 mcode，模型可留空。

重点试：交谈并作出决定后退出到标题、重新载入同一天，确认仍记得目标和选择，同时不会误认旧动作已经完成；检查长回复翻页、更多菜单和重复确认。

本次使用隔离存档验证了真实游戏界面与受控回复，另有读档和用量回归测试。真实 MiniMax 模型的工作效果仍需试玩验证；未调用付费模型做本次界面验收。

# 0.3.6 — 分开对话与管理窗口

- 走近伙伴交互：打开原生头像对话框，只保留对话、输入及选中事项的确认选择。
- F8：打开居中的独立窗口，沿用原有木质窗口样式，直接切换记录、工作和设置。
- 记录连续排列，支持滚轮、PageUp / PageDown 和拖动滚动条。查看旧记录时，新消息保留当前位置并显示跳转提示；只将实际进入可见范围的消息标记为已读。
- 待决定事项在 F8 删除、清除或撤销；点击事项转到 NPC 对话框答复。普通回车不隐式确认事项。
- 从 NPC 按 F8 保留输入草稿；从设置进入偏好与约定后，退出返回设置。

自主单人游玩目前仅提供方案，见仓库 `docs/autonomous-single-player-plan.md`。本版未更改伙伴角色、模型决策、睡觉结算或自主执行逻辑，也没有启动真实模型自由游玩。

界面验证采用真实游戏的隔离存档和可控回复，检查实际渲染、窗口切换、历史滚动、设置保存、事项答复与删除；这不代表自主游玩实验。

# 0.3.8 — 原生对话、恢复与自主续工

- F8 先显示未读伙伴对话，再进入原生四项选单：直接回复、历史记录、偏好和约定、设置和用量。直接回复立即打开输入框，保留草稿与待决定事项；历史仍用居中窗口。
- 体力偏低时伙伴会收尾并回到真实床位午休，按原生节奏恢复，体力满后醒来继续工作；夜间作息与跨日恢复仍单独记录。缺床、占床与不可达会给出原因。
- 补水在附近没有水源时专项查整张地图，并使用真实可补水位置。进食能力直接可见；种植使用实际可执行的单批工具。
- 补水首次实际成功即结束，不再尝试多余水格；浇水末帧正确释放动作，取消或预算截止前仍核对并保留已经生效的浇水结果。
- 修复伙伴行走和工具动画的更新链路，补齐进食动作和床上闭眼姿态，避免重复消费食物或重复工具效果。
- 开局及恢复后的自主唤醒会等待模型空闲，不再被关怀消息吞掉；关怀复用生活会话，普通完成事件不再导致新建生活会话。
- 未选中作业的自主决策在断线后可重新唤醒；已选中作业保留原任务，不重复派发。
- 刚选中的作业只显示等待执行，实际成功或失败来自原生结果。取消会等后台模型退出，避免旧任务和新任务重叠。
- 历史内容不再每帧重排；作息未变化时不重复保存，返程预估缓存并只在临近睡前计算。

旧存档无需迁移。午休标记缺省为夜间；原有暂停、取消和跨日工作记录保留。本版没有新增授权判断模型、proposal-id 审批门或中文关键词授权规则。

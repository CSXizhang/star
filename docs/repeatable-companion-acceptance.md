# 伙伴实机回归

“伙伴实机回归”固定指：隔离存档中，由正式 mcode 接收自然语言请求并执行，依据原生状态和 trace 验收。自动化单元测试不属于此名称。

默认固定运行三组，起点、请求和判定均版本化保存在 `tools/companion_acceptance/cases.json`。固定的是目标与验收，不规定模型的坐标、工具顺序或推理路径。

| 场景 | 固定行动 | 主要验收 |
| --- | --- | --- |
| care-guidance | 浇水、补水；动作中追加照料后的询问 | 作物浇完，新要求在工具边界送达 |
| harvest-logistics | 收获、拾取、入箱；再取出作物出货 | 中途箱内数量正确，最终出货数量正确、木材保留 |
| rest-forestry | 休息至 80 体力、采两棵成熟树、拾取入箱 | 真实上床恢复、继续工作、幼树保留 |

所有场景共用一次移动动画、碰撞、终态检查，并记录耗时、工具错误、聊天数量。不会替模型执行、重发失败任务或凭模型自述判通过。整套只启动一次隔离游戏，三组连续使用同一存档和模型会话；仅在动作与回合结束后重置测试布置和资源；不含公开分发的游戏资产。

回合结束后收起菜单再采样，不替玩家回答选项；拾取任务额外清理无关杂物属于范围偏离，应在报告中指出。

涉及掉落物时，旁观玩家停在远离任务区的农场可通行位置，并核对实际落点，避免抢先吸取物品或被农舍入口重定位后堵门。

运行 `tools/run-companion-presets.ps1 -ReleaseDir <完整包目录>`。默认三组即完整回归；用 `-Cases care-guidance` 可只复测对应组。原有 water-refill、harvest-store、rest-water、mature-trees、walk-pickup、walk-pickup-full 保留为故障定位子场景，不重复加入默认回归。

需要已登录 mcode、游戏和本地春季基础存档；可用 `-SavePath <存档目录>` 指定只读来源。已有游戏运行时拒绝启动。每组验收预算由 `-TimeoutSeconds` 设置，默认 600 秒；此预算属于测试，不是生产模型整轮时限。

每组结果在同一运行目录的 `evidence/<场景名>/`；总结果在 `.test-runs/presets-*/summary.md`，保留状态采样、trace、版本哈希和失败原因。缺少证据不能通过。画面观感、选项跨天、读档与执行中退出需单独验收，不由三组成功推定通过。

# 后端验证状态与成本基线

本项目是开源的，服务已经拥有 agent 命令行工具（Codex CLI、Kimi CLI、agy 等）的玩家。伙伴的行为质量取决于所选后端模型，而不同后端的行为验证程度不同。本文件如实记录哪些后端经过行为验收、哪些只有代码级回归，并说明如何贡献新的验证结果。

## 验证等级

| 等级 | 含义 |
| --- | --- |
| 行为验收 | 真实模型通过九场景决策评测，并完成隔离实机经营验收（真实存档、真实原生动作、账本证据） |
| 交互实测 | 真实模型跑通对话与交互流程（回复、工具调用、时延量测），但未做经营决策评测 |
| 代码级回归 | 提示注入、用量计量、会话轮换等接入路径有自动化测试，但没有真实模型的行为验收 |
| 未测试 | 没有任何接入验证 |

选择只有代码级回归或未测试的后端时，伙伴的经营判断、汇报习惯和失败处理都没有行为保证。发行包默认推荐已完成行为验收的后端。

## 贡献后端验证结果

欢迎为其他 agent 工具和模型补验证。两个层次：

1. **决策评测**：维护者本地九场景覆盖作物选择、剩余浇水、加工周期、营业窗口、失败预算、田区、清障和暂停事件；该轮约 6 万 token，脚本尚未公开分发。贡献同类评测时，请提供可复现的观察输入、任务、真实模型输出及判断标准，注明模型名、思考强度与运行日期。这是固定观察的隔离决策检查，不代表工具执行能力。

2. **实机经营验收（高成本，单轮百万级 token）**：在隔离环境用备份存档从既有匹配点接续经营至少一个游戏日，记录原生动作回执、账本增量、保存哈希与 token 用量，参照 `.test-runs/production-decision-20261001-r24/evidence/review-acceptance.json` 的格式。涉及付费模型与真实游戏，请自行承担成本并脱敏日志。

提交方式：按[参与开发](../CONTRIBUTING.md)流程开 issue 或 PR，标题注明后端与模型。维护者会把通过的结果登记到上表。

## 成本基线

r24 实机实测：一个活跃游戏日约 5 轮决策、30 次模型请求，输入 1,291,472（其中缓存命中 1,198,336，约 92.8%）、输出 11,719（含思考 2,551），共约 130 万 token。空闲日为 0（状态不变不唤醒模型）。

以 DeepSeek V4.1 Flash 按量计费估算（2026-08 起峰谷定价，[参考](https://www.ai-indeed.com/encyclopedia/31385.html)：空闲时段缓存命中输入 0.02 元/百万、未命中 1.0 元/百万、输出 4.0 元/百万，高峰时段约两倍）：

| 时段 | 每活跃游戏日 | 一个游戏季（28 天全活跃） |
| --- | --- | --- |
| 空闲时段 | 约 0.17 元 | 约 5 元 |
| 高峰时段 | 约 0.33 元 | 约 10 元 |

成本能成立的两个前提：

- **缓存命中率**。92.8% 的命中来自固定提示前缀（核心指令单一出处、主题按需加载）与同一后端长会话复用。换模型或换 CLI 会轮换会话并冷启动缓存，当日成本明显上升。
- **模型能力足够**。dsh + deepseek-flash 已跑通真实模型交互（见上表），但九场景决策评测与经营验收尚未做；低成本模型是否能完成同样的经营判断，需要按上节流程实测后再下结论。

订阅制后端（各 CLI 的最低套餐）能否 cover 一个活跃游戏日的 30 次请求 / 130 万 token，取决于各家配额策略，欢迎实测后按上节流程汇报，我们会把「最低套餐可用性」补进后端矩阵。

没有 agent 工具的玩家的内置方案（免装 CLI）尚在评估，确定后更新本节。

## 多人游戏

多人支持（建造、购买动物、搬迁建筑、躺床恢复）当前搁置，优先完成单人体验闭环。恢复排期时更新[玩家指南](companion-guide.md)的对应声明。
